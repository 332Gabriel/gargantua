# Gargantua

Simulação visual de um buraco negro com disco de acreção, inspirada no Gargantua de *Interstellar*. Canvas 2D puro, sem WebGL e sem dependências.

## O que tem

- Disco de acreção com gradiente de temperatura (laranja frio na borda, branco-azulado quente perto do horizonte).
- Anel de fóton brilhante ao redor do horizonte de eventos.
- Campo de estrelas com leve paralaxe.
- Interação com o mouse: arraste para perturbar as partículas do disco; clique para soltar matéria nova, que espirala e cai no buraco negro.

## Rodar local

Abra o `index.html` direto no navegador — não precisa de servidor nem build.

## GitHub Pages

Settings → Pages → Branch `main` → pasta `/root`. Depois de alguns minutos o site fica disponível em `https://332gabriel.github.io/gargantua/`.
